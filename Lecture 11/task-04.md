# Практичне завдання 4. Концентрація за абсорбансом

**Лекція 11. Блок:** Оптичний аналіз складу.

## Ситуація

Сигнали опорної проби й зразків уже скориговано за темновим сигналом; їх подано в однакових умовних одиницях. Калібрувальна модель чинна лише до заданої верхньої концентрації.

## Вхідні дані

```python
reference = 1000.0
signals = [1000.0, 800.0, 400.0, 50.0, 1050.0, 0.0]
slope_l_per_mmol = 0.20
range_mmol_l = (0.0, 2.5)
```

## Завдання

1. Для кожного відліку перевірте `I₀ > 0` і `0 < I / I₀ ≤ 1` перед обчисленням абсорбансу `A = −log₁₀(I / I₀)`.
2. За `A = k · c` оцініть `c` у ммоль/л. Поверніть абсорбанс і концентрацію або окремі статуси для недопустимого відношення та виходу за межі калібрування. Якщо відношення коректне, але калібрування нечинне, поверніть `A`, а концентрацію залиште `None`.
3. Відхиляйте непозитивний `k`, непозитивну опору або невпорядкований чи від’ємний діапазон концентрацій. Для одного коректного рядка відновіть пропускання за `10⁻ᴬ`.

Приймайте лише скінченні числові значення; `bool` не є виміряним числом. Для некоректних спільних параметрів можна піднімати `ValueError` з поясненням. Дробові результати перевіряйте з числовим допуском.

## Перевірки

- Однакові сигнали зразка та опори дають `A = 0` і `c = 0`.
- Перевірте верхню межу, подавши `I = I₀ · 10^(−k · 2.5)`; вона входить до діапазону з урахуванням числового допуску.
- Зіставте статуси для малого додатного сигналу, нульового сигналу й сигналу вище опори.

**Питання до висновку:** Чому додатне пропускання, для якого можна обчислити логарифм, ще не гарантує надійної оцінки концентрації?
