# Завдання 4. Випадковість і оцінювання невідомого значення

## Частина 1. Монета: спостережена частота та теоретична ймовірність

Відкрийте [Seeing Theory — Chance Events](https://seeing-theory.brown.edu/basic-probability/index.html#section1). Оберіть чесну монету: теоретична ймовірність орла (true probability) має дорівнювати 50%.

1. Киньте монету **3 рази** кнопкою **Flip the Coin**. Запишіть кількість орлів і решок.
2. Почніть нову серію з нульового лічильника (за потреби оновіть сторінку та знову перевірте ймовірність 50%). Киньте монету **7 разів** і запишіть результат.
3. Так само почніть нову серію та киньте монету **16 разів**.
4. Для кожної серії обчисліть спостережену частку орлів: `p̂ = кількість орлів / кількість кидків`. Порівняйте її з теоретичною ймовірністю `p = 0,5`. Різницю `(p̂ − 0,5) × 100` запишіть у **відсоткових пунктах**, зберігаючи знак.

| Кількість кидків n | Орлів H | Решок T | Спостережена частка орлів, % | Теоретична ймовірність, % | Різниця, в. п. |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 3 |  |  |  | 50 |  |
| 7 |  |  |  | 50 |  |
| 16 |  |  |  | 50 |  |

**Питання:** чи обов'язково різниця для 16 кидків буде меншою за модулем, ніж для 3? Поясніть за своїми результатами, чому окрема серія може відхилятися від теоретичної ймовірності.

## Частина 2. Оцінювання числа π випадковими точками

Відкрийте [Seeing Theory — Point Estimation](https://seeing-theory.brown.edu/frequentist-inference/index.html#section1). Скористайтеся ШІ, щоб **перекласти українською пояснення цієї секції**. У відповіді подайте власний короткий виклад (3–5 речень): що оцінюють, куди потрапляють випадкові точки та як за ними отримують оцінку π. Перевірте за оригіналом значення позначень і формули.

У симуляції `n` — кількість усіх точок, `m` — кількість точок усередині круга; оцінка `π̂ = 4m/n`. Не скидайте лічильник між етапами. Записуйте результат **відразу**, щойно лічильник показує потрібне `n`:

1. Натисніть **Drop 100 Samples** один раз: `n = 100`.
2. Натисніть **Drop 100 Samples** ще три рази: `n = 400`.
3. Натисніть **Drop 1000 Samples** двічі й **Drop 100 Samples** п'ять разів: `n = 2900`.

| Кількість точок n | Усередині круга m | Ваша оцінка π: 4m/n | Показане симулятором значення π | Відхилення 4m/n − 3,14159 |
| ---: | ---: | ---: | ---: | ---: |
| 100 |  |  |  |  |
| 400 |  |  |  |  |
| 2900 |  |  |  |  |

Якщо симулятор не показує `m` окремо, запишіть показану ним оцінку π й залиште стовпець `m` порожнім; відхилення обчисліть за цією оцінкою. Округлення може спричинити невелику різницю між вашими обчисленнями та показом симулятора.

**Питання:** як змінюється оцінка π із додаванням точок? Чи мусить її відхилення зменшуватися на кожному з трьох кроків? Порівняйте це зі своїми результатами для монети.
