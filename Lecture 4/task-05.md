## Два умовні джерела похибки

- **Шум показу датчика:** змоделюємо похибку нормальним розподілом із центром 0 В і стандартним відхиленням `σ = 0,10 В`. Це навчальна модель, а не твердження, що кожен датчик має нормальний шум.
- **Округлення до найближчого кроку:** якщо положення значення всередині кроку рівноймовірне, похибка округлення може бути рівномірною від `−√3 × 0,10 В` до `+√3 × 0,10 В`. Ці межі підібрано так, щоб теоретичне стандартне відхилення теж дорівнювало `0,10 В`. Рівномірність тут є **умовою моделі**, а не автоматичною властивістю будь-якого цифрового приладу.

В обох випадках **опорна похибка дорівнює нулю**. Ми порівнюємо форму розподілу *похибок окремих показів*, а не розподіл вибіркових середніх.

## Побудова двох гістограм

Відкрийте [Google Colab](https://colab.research.google.com/), створіть новий блокнот і запустіть код:

```python
import math
import random
import statistics
import matplotlib.pyplot as plt

rng = random.Random(42)
n = 1000
sigma = 0.10  # В

normal_errors = [rng.gauss(0, sigma) for _ in range(n)]
limit = math.sqrt(3) * sigma
uniform_errors = [rng.uniform(-limit, limit) for _ in range(n)]

fig, axes = plt.subplots(1, 2, figsize=(12, 4), sharex=True, sharey=True)
for ax, values, title in zip(
    axes,
    (normal_errors, uniform_errors),
    ('Нормальна модель шуму', 'Рівномірна модель округлення'),
):
    ax.hist(values, bins=30, range=(-0.4, 0.4), density=True)
    ax.axvline(0, color='black', linestyle='--')
    ax.set_title(title)
    ax.set_xlabel('Похибка окремого показу, В')
    ax.set_ylabel('Щільність')
plt.tight_layout()
plt.show()

for name, values in [('Нормальна', normal_errors), ('Рівномірна', uniform_errors)]:
    print(name, 'n =', len(values),
          'середнє =', round(statistics.mean(values), 4),
          'дисперсія =', round(statistics.variance(values), 6),
          's =', round(statistics.stdev(values), 4))
```

Код задає **фіксоване зерно генератора 42**: з ним ви й одногрупники отримуватимете ті самі дані, тому зможете обговорювати однакові графіки. Обидві гістограми мають однакові межі осей і кількість стовпчиків; порівнюйте їхню **форму**, а не суму висот. `statistics.variance` і `statistics.stdev` обчислюють *вибіркові* оцінки; вони не зобов'язані точно збігатися з параметрами генератора.

| Модель похибки | Теоретичне `σ`, В | Вибіркове середнє, В | Вибіркова дисперсія, В² | Вибіркове `s`, В | Яка форма гістограми? |
| --- | ---: | ---: | ---: | ---: | --- |
| Нормальна | 0,10 |  |  |  |  |
| Рівномірна | 0,10 |  |  |  |  |
