# Практичне завдання 3. Довірчий інтервал для середнього часу

**Мета:** за повторними показами з [першого завдання](task-01.md) побудувати 95% довірчий інтервал Стьюдента для середнього часу зупинки таймера та правильно пояснити, що він оцінює.

## Вхідні дані

Використайте **власні первинні покази секундоміра** з `task-01.md`:

- 13 показів для цілі **5,00 с** зі стовпця B;
- 13 показів для цілі **11,00 с** зі стовпця E.

Це **дві окремі серії**. Не змішуйте їх і не вводьте замість показів уже обчислені абсолютні чи відносні похибки. Зберігайте записані покази з точністю, яку відображав телефон.

## Побудова інтервалу онлайн

Відкрийте [Pearson Confidence Interval Calculator](https://www.pearson.com/channels/calculators/confidence-interval-calculator).

Для кожної серії окремо:

1. Виберіть **Raw Data** і вставте 13 показів часу через кому, пробіл або з нового рядка.
2. Встановіть **Confidence level: 95%**.
3. Увімкніть **Show visual breakdown** та **Show step-by-step solution**, потім натисніть **Calculate**.
4. Запишіть кількість показів `n`, вибіркове середнє `x̄`, вибіркове стандартне відхилення `s`, критичне значення `t` та обидві межі інтервалу. Збережіть знімок візуалізації результату.
5. Очистьте введення та повторіть усе для другої цілі.

У цьому завданні стандартне відхилення процесу `σ` невідоме. Потрібен **інтервал Стьюдента для середнього**, а не інтервал із відомим `σ` і нормальним коефіцієнтом 1,96. Для 13 показів кількість ступенів свободи дорівнює `n − 1 = 12`; для двобічного 95% інтервалу `t ≈ 2,179`.

## Перевірка обчислення

**Підказка до позначень.** `μ` — невідомий середній час ваших повторних зупинок за сталих умов, а `σ` («сігма») — невідоме стандартне відхилення **окремих** спроб навколо цього середнього. Із 13 спроб обчислюємо `x̄` як оцінку `μ` та вибіркове `s` як оцінку `σ`. Величина `SEM = s / √13` описує оцінене розсіювання **середніх нових серій по 13 спроб** за припущення незалежності. Мале `s` означає близькі між собою покази, але ще не означає влучання в ціль 5 або 11 секунд.

Звірте результат сервісу з формулою лекції, використовуючи `x̄` і **вибіркове** `s` своєї серії:

- `SEM = s / √n`;
- `h = t × SEM`;
- `нижня межа = x̄ − h`;
- `верхня межа = x̄ + h`.

Для кожної серії заповніть один рядок таблиці. Можна виконати перевірку в Excel поруч із первинними даними. Не округлюйте проміжні обчислення; `t ≈ 2,179` у тексті наведено для орієнтира, а для точного звіряння використайте критичне значення сервісу.

| Цільовий час, с | n | Середнє `x̄`, с | Вибіркове `s`, с | `SEM`, с | `t` | Нижня межа, с | Верхня межа, с | Чи належить ціль інтервалу? |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 5,00 | 13 |  |  |  |  |  |  |  |
| 11,00 | 13 |  |  |  |  |  |  |  |

## Як пояснити результат

1. Поясніть на своїх показах, що описує `s`, а що описує `SEM`. Чи доводить мале `s`, що ви зупиняєте таймер близько до цілі?
2. Яка з двох серій має ширший інтервал? Зіставте це з її вибірковим розсіюванням. Не приписуйте різницю лише зміні цілі з 5 до 11 секунд.
3. Чи потрапляє цільовий час у побудований для неї інтервал?
4. Закінчіть речення: «За використаних припущень цей інтервал оцінює середній час, на якому я ...».

**Важливо:** 5 і 11 секунд — відомі цілі вправи. Інтервал оцінює невідоме **середнє значення ваших повторних зупинок** за сталих умов. Він не означає, що 95% окремих показів лежать між його межами, і не надає 95% ймовірності вже побудованому інтервалу «містити ціль».

Інтервал Стьюдента в цій формі спирається на припущення про незалежні спроби зі стабільним приблизно нормальним розподілом. Людина може тренуватися протягом серії, втомлюватися або змінювати спосіб оцінки часу. Подивіться на графік показів за номером спроби з першого завдання: якщо бачите тренд чи зміну режиму, зазначте це як обмеження висновку.

## Додаткова візуалізація: багато повторних довірчих інтервалів

Відкрийте [Interpreting Confidence Intervals](https://rpsychologist.com/d3/ci/). Цей симулятор створює **власні нові випадкові вибірки**: він не приймає ваші 13 показів секундоміра. Тут ми перевіряємо зміст довірчого інтервалу на багатьох повтореннях, а не повторно рахуємо інтервал з Pearson.

1. Прочитайте англомовний текст **About the visualization**. Можна скористатися ШІ для перекладу українською. Подайте **власне пояснення на 4–6 речень**: що означають кожен намальований інтервал і справжнє середнє, що означає «95% confidence», чому інтервали бувають різної ширини й чому окремий інтервал може не накрити середнє. Звірте ці твердження з оригіналом. Не потрібно вставляти повний машинний переклад сторінки.
2. Установіть **Sample size = 5**. За потреби зменште **Speed**. Спостерігайте приблизно **20 нових інтервалів** і зупиніть анімацію кнопкою **Pause**. Оцініть, скільки з них не містять справжнього середнього; збережіть знімок екрана.
3. Оновіть сторінку, встановіть **Sample size = 50** і повторіть спостереження для приблизно **20 нових інтервалів**. Збережіть другий знімок екрана.

| Розмір вибірки в кожному повторенні | Скільки інтервалів переглянуто | Скільки не накрили справжнє середнє | Типова ширина: вужчі чи ширші? |
| ---: | ---: | ---: | --- |
| 5 | ≈20 |  |  |
| 50 | ≈20 |  |  |

**Поясніть:** (1) що змінилося в ширині інтервалів зі збільшенням вибірки; (2) чи гарантує рівень 95%, що саме 19 із ваших 20 інтервалів накриють середнє; (3) чому два інтервали з однаковим `n` можуть відрізнятися за шириною. Частка покриття близька до 95% лише в довгій серії повторень за умовами моделі, а результат двадцяти спостережень може помітно відрізнятися.

Пов'яжіть візуалізацію зі своїми обчисленнями: `s` описує розкид **окремих показів**, `SEM = s/√n` — оцінений розкид **середніх вибірок**, а довірчий інтервал будується **навколо середнього**, а не навколо кожного показу. Ця анімація не доводить, що саме ваші покази секундоміра нормально розподілені.
