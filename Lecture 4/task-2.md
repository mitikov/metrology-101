# Практичне завдання 2. Як допуск резисторів змінює напругу подільника?

**Мета:** дослідити, як можливі відхилення опорів двох резисторів від номіналу впливають на напругу, яку показує вольтметр.

## Вихідна схема

Відкрийте [приклад подільника напруги у Falstad](https://www.falstad.com/circuit/e-voltdivide.html). Використайте схему посередині з **двома послідовними резисторами** та джерелом **10 В**. Встановіть номінальний опір верхнього й нижнього резисторів по **10 кΩ**. Вимірюйте напругу **на нижньому резисторі** відносно нижнього вузла (землі); за потреби під'єднайте вольтметр паралельно йому.

Назвемо верхній резистор `Rверх`, нижній — `Rниз`. Для подільника без додаткового навантаження:

`Uвих = Uджерела × Rниз / (Rверх + Rниз)`.

Перш ніж змінювати опори, передбачте та перевірте напругу за номінальних `Rверх = Rниз = 10 кΩ`.

## Допуск і граничні сценарії

Для кожного рядка таблиці візьміть **два резистори з однаковим номіналом 10 кΩ та вказаним допуском**. Межі опору кожного з них:

- `Rмін = 10 кΩ × (1 − допуск / 100)`;
- `Rмакс = 10 кΩ × (1 + допуск / 100)`.

У Falstad перевірте два граничні поєднання:

1. `Rверх = Rмакс`, `Rниз = Rмін` — найменша вихідна напруга.
2. `Rверх = Rмін`, `Rниз = Rмакс` — найбільша вихідна напруга.

Спочатку обчисліть напруги за формулою, потім виставте відповідні опори в симуляторі та звірте показ вольтметра. Змінити номінал резистора у Falstad можна через **праву кнопку миші → Edit**.

| Ряд номіналів | Допуск для цього досліду | Мінімальний опір кожного резистора, кΩ | Максимальний опір кожного резистора, кΩ | Мінімальна `Uвих`, В | Максимальна `Uвих`, В |
| --- | ---: | ---: | ---: | ---: | ---: |
| E6 | ±20% |  |  |  |  |
| E12 | ±10% |  |  |  |  |
| E24 | ±5% |  |  |  |  |
| E48 | ±2% |  |  |  |  |
| E96 | ±1% |  |  |  |  |

**Контрольний приклад:** для допуску ±20% мінімальний опір становить 8 кΩ, максимальний — 12 кΩ. Якщо зверху 12 кΩ, а знизу 8 кΩ, отримаємо `Uвих = 10 × 8 / (12 + 8) = 4 В`. Якщо поміняти ці опори місцями, напруга буде іншою. Решту клітинок заповніть самостійно.

Ряди E6–E96 задають **доступні номінальні значення**, а допуск задає **межі фактичного опору**. У цьому досліді всім рядам відповідає один і той самий номінал 10 кΩ; наведені поєднання ряду й допуску є типовими прикладами, а не правилом, за яким назва ряду сама гарантує точність будь-якого резистора. Для реального компонента перевіряйте його допуск у специфікації.

## Візуалізація

Побудуйте графік за заповненою таблицею: по горизонталі — ряди E6, E12, E24, E48, E96, по вертикалі — вихідна напруга у вольтах. Нанесіть **дві серії точок** (мінімальну та максимальну напругу) і позначте **горизонтальну лінію 5 В** для номінального подільника. Так буде видно, як змінюється можливий діапазон напруги. Графік можна побудувати в Excel для вебу або в тій самій таблиці, де ви робили перше завдання.

Збережіть два знімки схеми Falstad для одного вибраного ряду: конфігурацію з мінімальною і конфігурацію з максимальною вихідною напругою. На кожному знімку мають читатися обидва опори та показ вольтметра.

## Перевірка інтуїції

Окремо виставте **однаковий фактичний опір** обох резисторів, але відмінний від номінальних 10 кΩ. Наприклад, для E6 спробуйте `Rверх = Rниз = 12 кΩ`. Запишіть, що показує вольтметр, і поясніть це через співвідношення опорів.

Для одного вибраного рядка обчисліть абсолютну й відносну похибки **вихідної напруги** відносно номінальних 5 В у двох граничних сценаріях:

- `ΔU = Uвих − 5 В`;
- `δU = (ΔU / 5 В) × 100%`.

Зберігайте знак похибки. Чи означає показ рівно 5 В, що обидва резистори обов'язково мають опір рівно 10 кΩ?

**Що здати:** заповнену таблицю, графік діапазонів напруги, два знімки схеми та коротке пояснення результату перевірки інтуїції. Граничні значення — це можливі межі за заданих допусків, а не розподіл імовірностей та не випадкова зміна опору одного й того самого резистора між показами.
