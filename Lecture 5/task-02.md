# Практичне завдання 2. Як залежність внесків змінює похибку каналу?

**Мета:** побачити розподіл суми випадкових внесків і перевірити, коли можна застосовувати квадратичне підсумовування (RSS).

**Орієнтовний час:** 18 хвилин. Потрібен браузер; встановлювати Python не потрібно.

## Перед дослідом: переклад

Відкрийте [Random Variable Visualizer — Terence Tao](https://teorth.github.io/tao-web/apps/random-variables.html).

- [ ] Перекладіть українською вступне пояснення та фрагмент **The model — one shared ω** у довідці **Language reference**. Можна використати ШІ або перекладач, але звірте результат з оригіналом. Подайте власний виклад на 3–5 речень: що змінюється на кожному кроці анімації, чим новий виклик `Normal(...)` відрізняється від повторного використання `X` і що показують точки та гістограма. Перекладіть `mean`, `standard deviation`, `independent`, `coupled`.

## Вихідна модель

Два внески вже приведені до **спільного виходу каналу** й вимірюються у мілівольтах. `X` і `Y` — випадкові похибки двох ланок, `Z` — їхня сума. Початкові середні дорівнюють нулю, СКВ становлять 3 і 4 мВ.

Замініть текст у полі **Program** на:

```text
X = Normal(0,3)
Y = Normal(0,4)
Z = X+Y
plot Z
statistic SD(Z)
```

Це мова моделі сайту, а не Python. У `Normal(0,3)` перше число є середнім, друге — **СКВ**, не дисперсією й не максимальною похибкою. Одиницю мВ ми задаємо змістом вправи; сайт сам не контролює фізичні одиниці.

## Три способи скласти ті самі за СКВ внески

Для кожного сценарію використовуйте окремий запуск:

1. Натисніть **Run program**. Якщо анімація стоїть на паузі, натисніть **Resume**.
2. Спостерігайте точки та гістограму до щонайменше **500 samples drawn**; натисніть **Pause**.
3. Запишіть фактичне число реалізацій, поточні середні й СКВ із **Values (live)** та значення **SD(Z)**.
4. Збережіть знімок результату до наступного запуску. Не змінюйте модель посеред серії без нового запуску програми.

| Сценарій | Другий рядок програми | Що означає зв'язок |
| --- | --- | --- |
| A | `Y = Normal(0,4)` | Окремий незалежний розіграш Y |
| B | `Y = (4/3)*X` | Y змінюється разом із X, зі спільним знаком |
| C | `Y = -(4/3)*X` | Y змінюється разом із X, із протилежним знаком |

Перед B і C передбачте, чи сума буде розсіюватися сильніше або слабше, ніж у A. СКВ Y в обох залежних сценаріях залишається заданим як 4 мВ; це не той самий внесок, що нова незалежна випадкова величина.

| Сценарій | Число реалізацій | Емпіричне СКВ X, мВ | Емпіричне СКВ Y, мВ | Емпіричне СКВ Z, мВ | СКВ Z за моделлю, мВ |
| --- | ---: | ---: | ---: | ---: | ---: |
| A | | | | | |
| B | | | | | |
| C | | | | | |

**Після спостереження** звірте результати з формулою лекції:

`σZ = √(σX² + σY² + 2ρσXσY)`.

Для A використайте `ρ = 0`, для B — `ρ = +1`, для C — `ρ = −1`. Підставляйте задані СКВ 3 і 4 мВ. Емпіричні оцінки з кінцевої серії не зобов'язані точно збігатися з модельними значеннями.

## Додайте систематичний внесок

Поверніть незалежний сценарій A, але змініть третій рядок на:

```text
Z = X+Y+6
```

Повторіть запуск для щонайменше 500 реалізацій. Запишіть середнє й СКВ Z та порівняйте з початковим сценарієм A. У моделі **+6 мВ — відоме стале зміщення**, а не випадковий внесок зі СКВ 6 мВ.

| Незалежний сценарій | Число реалізацій | Емпіричне середнє Z, мВ | Емпіричне СКВ Z, мВ |
| --- | ---: | ---: | ---: |
| Без сталого зміщення | | | |
| Зі сталим зміщенням +6 мВ | | | |

Приведіть модельне СКВ суми для A та стале зміщення до тиску, якщо чутливість каналу `S = 0,1 В/кПа`: спочатку переведіть мВ у В, потім використайте `Δp = ΔV/S`. Запишіть отримані характеристики **окремо**, у кПа.

## Питання до результатів

1. Чому однакові задані СКВ складових дали різну ширину розподілу суми? Для якого сценарію спрацював RSS і чому?
2. Що змінило додавання +6 мВ: центр розподілу, його ширину чи обидва? Чи можна підставити це зміщення в RSS як ще одне СКВ?
3. Як відрізняється ця задача від граничного бюджету, де відомо лише `|e₁| ≤ 3 мВ` та `|e₂| ≤ 4 мВ`? Яку гарантовану межу суми можна вказати тоді без додаткових відомостей?

**Обмеження:** модель задає нормальні розподіли й незмінні характеристики. Їхнє СКВ не є максимальною похибкою; нормальний розподіл не має скінченної гарантованої межі. Гістограма тут описує **окремі реалізації похибки каналу**, а не середні серій і не довірчий інтервал. Довша анімація поліпшує оцінку розподілу, але не робить сам канал менш шумним.
