# Практичне завдання 1. Ваги повторюють показ: чи означає це правильне вимірювання?

**Мета:** на керованій моделі розділити систематичне зміщення, випадкове розсіювання та дискретність показів.

**Орієнтовний час:** 20 хвилин. Потрібен браузер; обчислення можна виконати в Excel або калькуляторі.

## Перед дослідом: переклад і гра

- [ ] Перекладіть українською англомовне пояснення демонстрації та потрібні назви елементів керування. Можна використати ШІ або перекладач, але звірте результат з оригіналом. Подайте власний виклад на 3–5 речень: що моделюється, що ви змінюєте та що означає результат. Додайте переклад термінів `accuracy`, `precision`, `repeatability`, `zero bias`, `resolution`.

1. Відкрийте [Accuracy vs Precision](https://iwant2study.org/lookangejss/01_measurement/accuracyPrecision/).
2. Перегляньте чотири картини влучань. Центр мішені вважайте опорним значенням, точки — результатами повторних вимірювань.
3. Натисніть **Practice** і класифікуйте три запропоновані картини. Після відповіді натискайте **Continue**. Запишіть підсумковий рахунок та поясніть одну свою відповідь.

Мішень є якісною аналогією: вона допомагає розділити зміщення центру й розсіювання, але не задає числовий бюджет похибки. Не підмінюйте терміни лекції лише перекладом написів гри.

## Вихідні параметри ваг

Відкрийте [Gauge R&R — віртуальні ваги](https://omgames.app/play/gauge-r-r-repeatability-and-reproducibility-calculator-scale-simulator) та виберіть **Scale simulator**. Якщо панель мала, скористайтеся **Full screen**.

Установіть:

| Параметр | Значення |
| --- | --- |
| Reference weights | `20, 100, 200` — три еталонні маси, г |
| Operators | 2 |
| Trials | 3 |
| Operator σ | 0 г |
| Linearity | 0 г span |
| Repeatability σ | 0,35 г |
| Zero bias | 0 г |
| Resolution | 0,1 г |

У полі еталонних мас використовуйте крапку для дробових чисел, кому — для розділення мас. Для точного налаштування повзунка можна натиснути на нього й скористатися стрілками клавіатури; перевіряйте число біля назви параметра.

`Repeatability σ` задає СКВ випадкового внеску до округлення. `Zero bias` — сталий зсув; `Resolution` — крок відображення. Вплив оператора й залежність зміщення від маси тут вимкнені, щоб досліджувати по одному механізму.

## Чотири стани одного приладу

Перед кожним запуском запишіть прогноз: центр показів зміститься, розсіювання збільшиться чи покази стануть грубішими?

| Стан | Repeatability σ, г | Zero bias, г | Resolution, г |
| --- | ---: | ---: | ---: |
| A. Початковий | 0,35 | 0 | 0,1 |
| B. Зміщення нуля | 0,35 | +1,5 | 0,1 |
| C. Більший випадковий внесок | 1,00 | 0 | 0,1 |
| D. Грубіший дисплей | 1,00 | 0 | 1,0 |

Для кожного стану:

1. Установіть усі три параметри відповідного рядка. Решту залишайте за таблицею вихідних параметрів.
2. Натисніть **Run study**. Спостерігайте зважування та дочекайтеся **Complete: 18 measurements**. Використовуйте цей анімований запуск: режим **Run instantly** під час перевірки працював нестабільно.
3. Натисніть **Open in study form**. У таблиці **Measurement observations** знайдіть шість вимірювань з опорним значенням **100 г**: два оператори × три повтори.
4. Запишіть ці шість показів, зберігаючи їхню точність. Не змішуйте покази для різних еталонних мас.
5. Перед новим станом поверніться до **Scale simulator**. Збережіть результати попереднього стану: наступний запуск генерує нові випадкові внески.

## Таблиця й обчислення

Для кожної серії зі шести показів обчисліть:

- середній показ `x̄ = (x₁ + … + x₆) / 6`;
- середнє відхилення від еталона `Δ̄ = x̄ − 100 г`;
- розмах `W = max(xᵢ) − min(xᵢ)`.

| Стан | x₁, г | x₂, г | x₃, г | x₄, г | x₅, г | x₆, г | x̄, г | Δ̄, г | W, г |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| A | | | | | | | | | |
| B | | | | | | | | | |
| C | | | | | | | | | |
| D | | | | | | | | | |

Розмах шести показів не є СКВ і не є паспортною межею похибки. Через випадковість окрема коротка серія може відрізнятися від прогнозу; не перезапускайте її, щоб отримати «правильні» числа.

## Питання до результатів

1. У якому стані змінився переважно центр показів, а в якому — їхнє розсіювання? Зіставте прогноз із власними числами.
2. Якщо усереднити значно більше незалежних показів, яку складову можна зменшити у середньому результаті? Чи усуне це задане зміщення +1,5 г?
3. Чи означають однакові покази у стані D, що випадковий внесок зник? Що приховує грубіший дисплей?

**Обмеження:** це синтетичні ваги, а не перевірка реального приладу. Тут не досліджуються температурний вплив, гістерезис або дрейф. Показники ANOVA, `% study variation` та автоматичний висновок про прийнятність R&R для цього завдання не використовуйте.
