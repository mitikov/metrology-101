# Практичне завдання 3. Чи стала в’язкість

**Лекція 10. Блок:** Ротаційні та вібраційні віскозиметри.

## Ситуація

Дві серії зсуву знято за сталої температури. Потрібно перевірити сталість позірної в’язкості, не роблячи остаточного висновку про тип рідини за чотирма точками.

## Вхідні дані

```python
shear_rate_s_inv = [5, 10, 20, 40]
stress_1_pa = [2, 4.04, 8, 16]
stress_2_pa = [2, 3, 4.4, 6.4]
limit_pct = 5.0
```

## Завдання

1. Для кожної точки обчисліть позірну в’язкість `η = τ / γ̇` у Па·с.
2. Для кожної серії поверніть медіану в’язкості, абсолютні відносні відхилення від неї у відсотках та номери точок, для яких відхилення строго більше за 5 %. Поверніть окремий статус для всієї серії: чи є такі точки.
3. Відхиляйте порожні або різні за довжиною масиви, непозитивні значення напруження й швидкості зсуву та від’ємний поріг. Медіану можна обчислити через `statistics.median`.

Приймайте лише скінченні числові значення; `bool` не є виміряним числом. Для некоректних спільних параметрів можна піднімати `ValueError` з поясненням. Дробові результати перевіряйте з числовим допуском.

## Перевірки

- За однакової в’язкості всіх точок жодне відхилення не спрацьовує.
- Рівно 5 % не перевищує поріг (допускається малий числовий допуск).
- Перевірте обидві задані серії, нульову швидкість зсуву й різні довжини масивів.

**Питання до висновку:** Чому перевищення навчального порога не є остаточним доказом неньютонівської поведінки?
