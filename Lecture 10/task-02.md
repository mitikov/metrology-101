# Практичне завдання 2. Оптичний перехід на дзеркалі

**Лекція 10. Блок:** Точка роси та конденсаційні вологоміри.

## Ситуація

Дзеркало послідовно охолоджують. Краплі можуть послабити відбите світло, але короткий провал ще не підтверджує перехід. У задачі використано навчальне порогове правило, а не модель теплової рівноваги реального вологоміра.

## Вхідні дані

```python
temperature_c = [19, 18, 17, 16, 15, 14, 13]
reflection = [1.00, 0.83, 0.97, 0.85, 0.82, 0.81, 0.80]
threshold = 0.86
required_count = 3
```

## Завдання

1. Знайдіть першу серію з `required_count` послідовних відліків, для яких відбиття не більше за поріг. Поверніть індекс початку серії (від нуля) й відповідну температуру, без інтерполяції. Індекс підтвердження вкажіть окремо.
2. Поверніть індекси початку всіх коротких серій, які закінчилися відліком вище порога. Якщо коротка серія доходить до кінця запису, позначте її як непідтверджену через нестачу даних, а не як нестійкий провал.
3. Якщо підтвердженої серії немає, поверніть `None` замість температури та поясніть, чи запис закінчився під час короткої серії. Відхиляйте порожні або різні за довжиною масиви, нестрого спадні температури, відбиття або поріг поза [0, 1] та неціле або недодатне `required_count`.

Приймайте лише скінченні числові значення; `bool` не є виміряним числом. Для некоректних спільних параметрів можна піднімати `ValueError` з поясненням. Дробові результати перевіряйте з числовим допуском.

## Перевірки

- Відлік рівно на порозі зараховується до серії.
- Окремий провал із відновленням, рівно три відліки під порогом і два відліки під порогом наприкінці дають різні результати.
- Перевірте, що початок серії та підтвердження не переплутані.

**Питання до висновку:** Чому навіть підтверджений оптичний перехід сам по собі не доводить, що дзеркало досягло рівноважної точки роси?
