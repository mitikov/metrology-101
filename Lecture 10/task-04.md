# Практичне завдання 4. Густина за ослабленням сигналу

**Лекція 10. Блок:** Радіоізотопні густиноміри.

## Ситуація

Сигнал детектора та опорний відлік містять однаковий фон. Склад проби, довжина шляху й геометрія сталі. Працюємо лише з синтетичним журналом; фізичне обладнання не потрібне.

## Вхідні дані

```python
background_cps = 100
reference_raw_cps = 1100
sample_raw_cps = [770, 470, 1100, 100, 1150]
path_m = 0.10
mass_attenuation_m2_kg = 0.010
```

## Завдання

1. Відніміть фон від опорного й кожного сирого відліку. Модель: `r = I / I₀ = exp(−μₘ · ρ · ℓ)`, де `I` та `I₀` — скориговані сигнали, `ℓ` у м, `μₘ` у м²/кг.
2. Для `0 < r ≤ 1` поверніть `r`, густину в кг/м³ та статус. Використайте натуральний логарифм; для `r ≤ 0` або `r > 1` густина має бути `None` з відповідною причиною.
3. Відхиляйте непозитивний скоригований опорний сигнал, непозитивні `ℓ` або `μₘ` та від’ємний фон. Для одного коректного рядка підставте оцінену густину в пряму модель і порівняйте відновлене `r` з початковим.

Приймайте лише скінченні числові значення; `bool` не є виміряним числом. Для некоректних спільних параметрів можна піднімати `ValueError` з поясненням. Дробові результати перевіряйте з числовим допуском.

## Перевірки

- Відлік дорівнює опорі: `r = 1`, густина дорівнює нулю в межах моделі.
- Відлік дорівнює фону або перевищує опору: обидва рядки некоректні з різних причин.
- Перевірте, що результат не змінюється, якщо додати однакову сталу до сирих сигналів і фону.
