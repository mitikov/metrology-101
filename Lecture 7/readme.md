## Як використовувати

Завдання розраховані на практичне заняття або роботу після лекції. Їхній час не включено до 60 хвилин викладу. У парі учасники обмінюються аргументами; за самостійної роботи студент письмово розглядає обидві ролі. Приховані картки відкривають після фіксації початкового рішення.

Для історій використано першоджерела зі звіту про Buncefield, USGS, WIKA та NASA. Посилання подано в самих завданнях. Усі навчальні таблиці сконструйовані окремо, вони не є даними згаданих організацій. У пошукових питаннях студент має знайти документацію конкретного приладу самостійно.

Під час перевірки оцінюйте обґрунтування, правильність одиниць, роботу з відсутніми даними й те, чи відповідає висновок наявним доказам. Кількість цифр у відповіді та охайність графіка самі по собі не підтверджують правильності.

Джерела формату й матеріали для історій перевірено 27.10.2026. PDF-звіт Buncefield підтверджено через індексований текст документа; його пряме відкриття під час підготовки повертало тайм-аут, тому додано альтернативний вхід через HSE. Зовнішні інтерактивні сервіси для виконання не потрібні.
