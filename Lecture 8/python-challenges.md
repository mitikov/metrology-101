## Challenge 1. Перепад тиску й накопичений об’єм

### Ситуація

Дифперетворювач вимірює перепад на звужувальному пристрої. Потрібно перетворити часовий ряд на витрату й обчислити об’єм, що пройшов за час запису.

Приймаємо односторонній потік однорідної нестисливої рідини, сталу густину й незмінну геометрію. Коефіцієнт k заданий для навчальної моделі. Поправки реального промислового витратоміра в цій задачі не обчислюємо.

### Вхід

```python
times_s = [0.0, 10.0, 25.0, 40.0]
delta_p_pa = [0.0, 1000.0, 4000.0, 1000.0]
k_m2 = 0.001
rho_kg_m3 = 1000.0
```

Модель:

`Q_v = k · sqrt(Δp / ρ)`.

Δp вимірюють у Па, ρ — у кг/м³, k — у м², Q_v — у м³/с. Після ділення Δp на ρ та добування кореня маємо м/с; множення на k дає м³/с.

На кожному інтервалі `[times_s[i], times_s[i + 1])` витрату вважаємо сталою й рівною значенню за лівим показом. Об’єм інтервалу дорівнює добутку цієї витрати на його тривалість. Це задана модель між вимірюваннями, а не твердження, що реальний потік завжди змінюється сходинками.

### Завдання

Реалізуйте функцію перерахунку одного перепаду у витрату та функцію обробки всього запису.

Поверніть:

- список витрат у м³/с для всіх чотирьох показів;
- три інтервали з початком, кінцем, тривалістю та об’ємом у м³;
- загальний об’єм у м³ та літрах.

Останній показ задає витрату в кінцевий момент, але не створює четвертого інтервалу: кінця цього інтервалу немає у вхідних даних.

Відхиляйте різні довжини списків, менш ніж дві точки, нечислові або нескінченні значення, час, що не зростає строго, непозитивні k чи ρ та від’ємний перепад. Для цієї задачі можна використовувати `ValueError` з поясненням. Не підміняйте некоректний запис нульовим об’ємом і не пропускайте його мовчки.

Окремо перевірте обернення `Δp = ρ · (Q_v / k)²` для допустимих перепадів.

### Перевірки

- Нульовий перепад дає нульову витрату.
- Для Δp = 1000 Па за заданих k та ρ витрата дорівнює 0,001 м³/с.
- Сталий перепад на всіх інтервалах має дати той самий об’єм, що й стала витрата, помножена на повну тривалість.
- Перевірте нерівні інтервали часу з основного набору.
- Зміна лише останнього допустимого показу змінює кінцеву витрату, але не накопичений об’єм за прийнятим правилом лівого показу.
- Перевірте повторений час, спадний час, різні довжини списків, ρ = 0, k = 0, Δp < 0, `None`, NaN і `True`.
- Пряме та обернене перетворення мають відновлювати початковий допустимий перепад із числовим допуском.

**Підказка:** перерахунок показу й накопичення за часом — різні операції; тривалість кожного інтервалу може бути своєю.

**Питання до висновку:** чому середня за часом витрата може відрізнятися від витрати, обчисленої за середнім за часом перепадом? Порівняйте два однаково тривалі режими з перепадами 0 та 4000 Па, не змінюючи k і ρ.

## Challenge 2. Два вікна імпульсного обліку

### Ситуація

Турбінний витратомір передає імпульси. Коефіцієнт K задає їх кількість на одиницю об’єму. Програма повинна відрізняти об’єм за вікно від середньої витрати та кроку її цифрового представлення.

### Вхід

```python
k_pulses_per_m3 = 20_000.0
windows = [
    {"id": "A", "pulses": 7, "duration_s": 1.0},
    {"id": "B", "pulses": 73, "duration_s": 10.0},
]
```

Це два окремі записи. Не припускайте, що коротке вікно вкладене в довге або що потік у них однаковий.

Залежності:

- `f = N / Δt`;
- `Q_v = f / K`;
- `V = N / K`;
- `flow_step = 1 / (K · Δt)`.

N — невід’ємне ціле число імпульсів, Δt — секунди, K — імп/м³, f — імп/с. Q_v та крок витрати мають одиницю м³/с, V — м³. K тут не має розмірності коефіцієнта k із Challenge 1.

### Завдання

Для кожного вікна поверніть його ідентифікатор, частоту, об’єм у м³ та літрах, середню витрату в м³/с та л/хв, а також крок витрати в тих самих одиницях.

Перевірте цілісність і невід’ємність N, додатність та скінченність K і Δt. Неправильний тип, дробове N, `bool`, NaN чи нескінченність відхиляйте явно. Некоректні дані не повинні повертати нульову витрату.

Для N = 0 обчислений об’єм та середня витрата за вікно нульові. Додайте пояснення, що порожнє коротке вікно не доводить фізичної відсутності повільного потоку або справності каналу.

Порівняйте два вікна словами: швидкість оновлення, крок представлення та можливість помітити коротку зміну. Не називайте крок повною похибкою приладу.

### Перевірки

- N = 0 та N = 1 за додатних K і Δt.
- За однакових K та Δt подвоєння N подвоює об’єм і середню витрату.
- За того самого N подвоєння Δt не змінює об’єм, але вдвічі зменшує середню витрату й крок.
- Перевірте співвідношення `K · V = N` та `K · Q_v · Δt = N` із числовим допуском.
- Для заданого K крок при Δt = 1 с дорівнює 3 л/хв.
- Перевірте Δt = 0, K = 0, від’ємне й дробове N, `True`, NaN та неправильний тип.

**Підказка:** об’єм одного імпульсу незмінний у прийнятій калібровці, а внесок цього імпульсу в середню витрату залежить від тривалості спостереження.

**Питання до висновку:** чому збільшення вікна не завжди покращує результат для керування швидкозмінним потоком, навіть якщо числовий крок стає меншим?

## Challenge 3. Відбір принципів без вгадування даних

### Ситуація

Потрібно попередньо перевірити три вимірювальні принципи для чотирьох середовищ. Завдання перевіряє логіку фізичних обмежень, а не вибір конкретного промислового приладу.

### Вхід

```python
media = [
    {"id": "water", "conductivity_us_cm": 500.0,
     "gas_volume_percent": 0.0, "scatterers_follow_flow": False},
    {"id": "oil", "conductivity_us_cm": 0.01,
     "gas_volume_percent": 0.0, "scatterers_follow_flow": False},
    {"id": "suspension", "conductivity_us_cm": 800.0,
     "gas_volume_percent": 2.0, "scatterers_follow_flow": True},
    {"id": "unknown", "conductivity_us_cm": None,
     "gas_volume_percent": 0.0, "scatterers_follow_flow": None},
]
```

Електропровідність задана у мкСм/см. Об’ємна частка газу задана числом від 0 до 100 у відсотках: `0.5` означає 0,5 %, а не 50 %. Поле `scatterers_follow_flow` означає наявність придатних розсіювачів, що рухаються разом із рідиною. Тут булеві значення потрібні за змістом поля.

У всіх записах труба повністю заповнена, акустичний контакт придатний, інші вимоги поза заданими правилами вважаємо виконаними.

Навчальні правила:

| Принцип | Умови |
| --- | --- |
| `electromagnetic` | Електропровідність не менше 5 мкСм/см |
| `transit_time` | Частка газу не більше 0,5 % та відсутність розсіювачів |
| `doppler` | Наявність придатних розсіювачів, що рухаються з рідиною |

Ці пороги й спрощення належать лише задачі. Зокрема, правило про відсутність розсіювачів не означає, що всі реальні часові витратоміри заборонено застосовувати до будь-якої рідини з частинками.

### Завдання

Для всіх 12 пар «середовище — принцип» поверніть статус і результати перевірки кожної потрібної умови:

Використовуйте для окремих умов `pass`, `fail` і `unknown` з поясненнями. Відсутній ключ і `None` означають невідоме, а не нуль чи `False`.

Невідому провідність не потрібно перевіряти для доплерівського принципу: перевіряйте лише поля, які вимагає відповідний метод. Якщо одночасно є `fail` та `unknown`, фінальний статус — `not_suitable`, але збережіть обидві причини.

Некоректне числове поле — від’ємна провідність, частка газу поза [0, 100], NaN, нескінченність або неправильний тип — позначайте `unknown` із причиною `invalid_data`. Для поля розсіювачів приймайте лише `True`, `False` або невідоме значення, без автоматичного перетворення рядків на `bool`.

### Перевірки

- Електромагнітний принцип має пройти заданий поріг для води та бути відхиленим для оливи.
- Перевірте результат кожного принципу для суспензії, зберігаючи конкретні причини.

- Перевірте `None` та повністю відсутній ключ.

**Підказка:** зберігайте результати окремих умов, щоб підсумковий статус можна було пояснити.

**Питання до висновку:** чому успішне випробування накладного ультразвукового приладу в кейсі Endeavor не доводить придатності будь-якого ультразвукового витратоміра для довільної брудної води?
